# Frozen configurations

`models.json` and `rewriters.json` define the initial hosted routes and rewrite prompt. The three replication JSON files freeze MiniMax/GLM 4.7, the GLM successor, and GLM 5.1/DeepSeek V4 Pro. `history_tier_examples.json` preserves the style conditions and semantic checklist example. The V7/V8 SWE-bench matrix JSON and YAML files bind all continuous-compaction arms, providers, model history representations, compressor settings, dataset hash, and step limits. Task-file references point to `manifests/tasks/` in this archive.
